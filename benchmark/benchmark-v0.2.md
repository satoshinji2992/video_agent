# VideoAgentBench：开放式视频创作 Agent 综合评测基准

版本：v0.2（Pilot Benchmark）

## 1. 研究目标

VideoAgentBench 旨在评测 AI Agent 能否从普通用户自然、模糊、不完整的需求出发，自主完成完整的视频制作过程。

不同于传统 Text-to-Video Benchmark，本评测重点关注：

1. **信息收集（Research）**：主动搜集、验证、筛选信息与素材。
2. **意图理解（Intent Alignment）**：理解用户没有明确写出的目标和审美偏好。
3. **规划能力（Planning）**：自主设计叙事结构、分镜、制作流程与工具调用。
4. **视觉制作（Visual Production）**：生成或编辑画面，合理使用特效与动画。
5. **音画编排（Editing）**：完成镜头组织、转场、配音、音乐、字幕和节奏设计。
6. **自检与迭代（Reflection & Revision）**：发现问题，根据自然语言反馈修改成片。

核心原则：

**用户只提出创作目标，不负责指导 Agent 如何制作视频。**

评测系统不预先规定唯一正确的分镜、工具或创作方法，而是根据最终结果和可验证的执行过程进行综合评价。

## 2. Benchmark 任务设置

初版包含三个综合任务，覆盖不同的视频创作场景。

| 任务   | 类型     | 主要挑战                           | 建议时长  |
| ------ | -------- | ---------------------------------- | --------- |
| Task 1 | 科学科普 | 网络研究、事实核查、科学可视化     | 60–100 秒 |
| Task 2 | 商业宣传 | 品牌理解、素材筛选、情绪与节奏编排 | 30–60 秒  |
| Task 3 | 创意短片 | 叙事规划、视觉特效、镜头连续性     | 45–90 秒  |

每个任务均包含初次创作和一次后续修改。

### Task 1：DART — 小行星撞击科普

**场景：** 普通内容创作者希望制作一期科学短视频，对专业知识了解有限，需要 Agent 自行完成资料研究和内容表达。

**用户原始提示词：**

> 最近刷到 NASA 拿飞船撞小行星那个事，听说真的把轨道撞歪了？
>
> 我想做个一分钟多点的视频发 B 站，讲讲这件事。最好有点电影感，但别搞成世界末日那种，也别像上课一样无聊。
>
> 要让没学过航天的人也能看明白。资料和素材你自己找吧，直接给我做成视频。

**评测者隐藏关注点：**

- 是否主动检索 NASA、ESA 等可靠来源。
- 是否正确解释 DART 实验目的与结果。
- 是否区分双小行星绕转周期和日心轨道变化。
- 是否识别真实观测影像、模拟动画和艺术化镜头。
- 是否能够通过空间动画解释原本抽象的科学概念。
- 是否在准确性、观赏性和有限时长之间合理取舍。
- 是否避免夸大实验效果和制造虚假危机。

**第二轮用户反馈：**

> 感觉开头还是有点营销号，而且中间那个轨道变化我没太看懂。
>
> 其他部分我觉得还行，改一下吧。

考察 Agent 能否识别反馈对应的问题，修改开头和科学可视化，同时保留其他有效内容。

### Task 2：Coffee Launch — 独立咖啡店宣传视频

**场景：** 小型实体商家希望利用已有手机拍摄素材制作社交媒体宣传片。用户没有影视制作知识，对视觉风格只有主观描述。

**随任务提供的素材包：**

- 12–20 段未经剪辑的手机视频，包含店面、咖啡制作、产品特写、顾客活动等。
- 若干照片、店铺 Logo 和菜单信息。
- 一份简短的店铺资料，包含真实营业信息与品牌定位。
- 部分素材存在抖动、重复拍摄、曝光问题或无效内容。

上述素材由 Benchmark 统一提供，不要求参测 Agent 自行寻找真实商家。

**用户原始提示词：**

> 我们咖啡店快开业了，拍了一堆素材，你帮我做个能发抖音的宣传视频吧。
>
> 想要那种有质感、看着很舒服的感觉，不要太像硬广。最好能让人看了想来店里坐坐。
>
> 视频不用太长，你自己看着安排。

**评测者隐藏关注点：**

- 能否从大量原始素材中筛选高质量镜头。
- 能否通过已有资料理解店铺的风格与卖点。
- 能否自主构建合理的宣传叙事，而非简单拼接素材。
- 是否合理运用调色、文字动效、音效与音乐节奏。
- 能否在品牌宣传与生活化表达之间取得平衡。
- 是否避免虚构价格、优惠、营业时间或产品信息。
- 是否符合短视频平台的观看习惯。

**第二轮用户反馈：**

> 感觉有点太精致了，像大品牌广告，不太像我们这种小店。
>
> 能不能更有人情味一点？不过那个咖啡制作的部分我挺喜欢的，尽量保留。

考察 Agent 是否能够把模糊的审美反馈转换为具体修改，并避免不必要的重新制作。

### Task 3：Time Glitch — 时间异常科幻短片

**场景：** 个人创作者拍摄了一批普通生活镜头，希望 Agent 将其制作成具有故事性和视觉特效的科幻短片。

**随任务提供的素材包：**

- 8–15 段同一人物、同一场景的原始视频。
- 包含人物进出房间、拿取物品、观察时钟、走廊行走等行为。
- 若干空镜头及环境声素材。
- 素材不包含预先制作的特效。

**用户原始提示词：**

> 我拍了几段日常生活的视频，想试试能不能剪成一个科幻小短片。
>
> 大概就是一个人发现时间好像出了问题，身边的东西开始变得不正常。
>
> 想要有点悬疑感，最好能有几个让人眼前一亮的特效，但不要那种廉价的 AI 科幻感。
>
> 故事和镜头你来设计，最后做成一个完整的小短片就行。

**评测者隐藏关注点：**

- 是否能够根据已有镜头反向规划可实现的故事。
- 是否具有清晰的事件发展、悬念和结尾。
- 是否通过画面而非过量文字解释剧情。
- 是否合理设计时间停滞、物体异常、画面重复等特效。
- 特效是否符合人物动作、空间位置、光照和运动连续性。
- 人物、服装、物体及场景是否在不同镜头中保持一致。
- 是否有效运用声音设计、视觉节奏和蒙太奇强化情绪。
- 是否避免无意义的炫技镜头。

**第二轮用户反馈：**

> 效果挺酷的，但是看起来有点像恐怖片了。
>
> 我其实想要的是那种神秘、有点孤独的感觉，不一定要吓人。
>
> 结尾能不能再有意思一点？

考察 Agent 能否修改叙事基调、音乐、节奏和结尾设计，而不是仅仅调整颜色或添加特效。

## 3. 评测指标

总分 100 分。

| 指标                    | 权重 | 评价内容                             |
| ----------------------- | ---- | ------------------------------------ |
| Intent Alignment        | 25   | 用户目标理解、审美匹配、隐含需求处理 |
| Research & Grounding    | 15   | 事实核查、素材检索、来源可靠性       |
| Planning & Storytelling | 20   | 整体结构、叙事逻辑、镜头规划         |
| Visual & VFX Quality    | 15   | 画质、一致性、特效合理性             |
| Editing & Sound         | 15   | 镜头衔接、音画同步、节奏与字幕       |
| Execution & Delivery    | 10   | 自主执行、错误恢复、最终交付         |

所有评分采用统一量表，并结合不同任务设置专门的评价锚点。

例如，Task 1 的 Research 重点是外部事实验证；Task 2 重点是正确理解并使用提供的商家资料；Task 3 重点是理解素材限制，避免引入与故事或已有画面相矛盾的信息。

### 3.1 用户意图对齐

重点回答：

- 成片是否解决了用户实际提出的问题？
- Agent 是否正确理解主观审美描述？
- 是否合理补全未明确提出、但完成任务所必需的工作？
- 是否出现过度执行、错误推断或偏离主题？

不能因为 Agent 没有采用评测者偏好的镜头设计就直接扣分。

### 3.2 信息收集与真实性

重点考察：

- 是否知道哪些信息需要外部验证。
- 是否能判断信息来源是否可靠。
- 是否区分事实、推断与虚构内容。
- 是否正确使用给定素材。
- 是否避免编造原始素材中不存在的事实。

### 3.3 规划与叙事

重点考察：

- 视频是否有明确的结构和信息层次。
- 镜头是否具有叙事作用。
- 内容是否符合目标受众。
- 是否能够合理控制时长与节奏。
- 最终作品是否展现整体规划，而非局部片段的机械拼接。

### 3.4 视觉与特效

重点考察：

- 主体、场景和视觉风格的一致性。
- 动画、合成、跟踪及转场的技术完成度。
- 特效是否能够有效传达信息或推进叙事。
- 是否存在不自然的运动、物体变形、空间关系错误。
- 是否避免为了展示特效而牺牲用户目标。

### 3.5 音画编排

重点考察：

- 镜头之间的时间与空间连续性。
- 音效、音乐和旁白对叙事的支持。
- 字幕及文字信息的准确性与可读性。
- 剪辑节奏是否符合情绪变化。
- 是否存在突兀剪辑、音频断裂、严重不同步等问题。

### 3.6 执行与交付

重点考察：

- 是否自主完成必要的制作步骤。
- 是否合理调用工具并处理失败。
- 是否提交可播放的完整视频。
- 是否存在明显的技术错误或缺失。
- 是否在有限预算内完成任务。

交付失败应当单独记录，不能仅靠其他指标的高分抵消。

## 4. 用户反馈与迭代评测

每个任务分为两个阶段。

**Stage A — Initial Creation**

Agent 接收用户原始提示词和允许使用的素材，自主制作第一版完整视频。

**Stage B — User Revision**

第一版完成后，评测系统提供自然语言反馈，要求 Agent 修改已有作品。

修改阶段单独评价三个指标：

| 指标                 | 含义                         |
| -------------------- | ---------------------------- |
| Revision Compliance  | 是否真正解决用户提出的问题   |
| Content Preservation | 是否保留不需要修改的有效内容 |
| Quality Improvement  | 修改后的总体质量是否提升     |

同时记录额外制作成本、修改时间和不必要的内容变化。

不得仅通过重新生成整条视频来获得更高的修改得分。应根据修改范围及结果评价其效率和针对性。

## 5. 评测流程

### 5.1 输入

每个任务包含：

- `user_prompt.txt`：自然语言用户需求。
- `assets/`：可选原始素材及必要资料。
- `task_metadata.json`：评测使用的任务元数据。
- `revision_prompt.txt`：第一阶段完成后才开放的修改需求。

所有参测 Agent 在同一任务中获得相同的用户输入和初始素材。

### 5.2 执行

Agent 可以使用：

- 网络搜索、网页浏览和资料检索。
- 视频生成、图像生成和音频生成模型。
- Python、FFmpeg、Blender 等制作工具。
- 视频编辑软件及其他合法工具。

不限制具体实现架构，但必须完整记录工具调用、外部资源使用及主要制作步骤。

比较不同 Agent 时，应控制可用工具、调用预算、素材范围和重试次数，或将不同工具配置明确划分为独立赛道。

### 5.3 输出

最低要求：

- `final_v1.mp4`：初始完整成片。
- `final_v2.mp4`：接收反馈后的修改版。
- `execution_log.jsonl`：可审计的执行轨迹。
- `assets_manifest.json`：使用的外部素材和来源。

建议额外保存脚本、分镜、工程文件及中间渲染结果，用于分析 Agent 的规划行为，但不应要求普通用户提示词主动提出这些文件。

### 5.4 评估

采用混合评测机制。

**自动评估：** 检测成片完整性、时长、编码、分辨率、字幕时间、音频峰值、黑屏及其他可程序化检测的问题。

**多模态模型评估：** 结合视频、用户需求和相关证据，辅助判断语义匹配、事实性、叙事结构和视觉异常。

**人工盲评：** 由至少三名评审在不知道系统身份的情况下评价整体观看体验、审美和意图匹配情况。

**真实用户评估：** 由符合目标受众的用户独立评价成片是否满足需求，作为用户意图对齐的重要外部验证。

评估时应避免把同一个多模态模型的偏好直接当作最终客观标准。

## 7. 公平性与可复现性

1. Task 1 的关键事实应提供评测时间点和权威参考来源；对于动态网络内容，可以使用冻结的检索环境或记录检索日期。
2. Task 2 和 Task 3 使用标准化素材包，确保各系统输入一致。
3. 所有系统采用一致的预算及执行终止条件。
4. 保留原始提示词，不允许在评测前将自然语言需求改写成详细制作清单。
5. 允许 Agent 主动提出澄清问题，但应记录并评价其必要性。除预先定义的答复外，不引入临时人工指导。
6. 对每个任务进行多次独立运行，报告波动性。
7. 区分模型本身的能力、外部工具能力与整体 Agent 系统能力。
8. 人工评测采用统一评分说明，并报告评审间一致性。

## 8. 初版实验设计

本版本以三个综合任务作为 Pilot Benchmark，不将它们视为具有充分统计代表性的正式大规模数据集。

建议首先选择三类参测系统：

- **Workflow Baseline**：预先固定的研究、脚本、生成与剪辑流水线。
- **General-purpose Agent**：能够自主调用多种工具的通用智能体。
- **Specialized Video Agent**：针对视频制作流程优化的专门系统。

通过相同任务比较：

- 具有自主规划能力的系统是否优于固定工作流。
- 自主信息检索能否改善事实准确性与内容表达。
- 视觉特效质量提升是否必然带来用户满意度提升。
- Agent 是否能够有效理解并执行模糊的修改反馈。
- 自主执行是否显著增加成本，以及这些成本是否值得。

完成 Pilot 验证后，可将三类场景扩展为更大规模任务集，并增加不同难度的自然语言提示词、用户群体、素材条件和反馈类型。

## 9. 预期研究价值

VideoAgentBench 关注现有视频质量评测难以完整体现的能力：从用户目标出发，自主组织并完成一项多步骤、跨工具、涉及事实与审美判断的创作任务。

相比单独衡量画面清晰度、运动真实性或指令遵循程度，VideoAgentBench 希望回答更完整的问题：

**一个 AI Agent 能否像实际的视频创作者一样，理解客户需求、主动研究、制定方案、组织制作、判断质量，并根据反馈交付真正符合预期的作品？**

这也是本 Benchmark 的核心研究问题。
